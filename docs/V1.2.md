# ResearchEvolve v1.2 — Isolated Codex-native Actors

v1.2 replaces the Codex Plugin MVP's default manual actor exchange with auditable, isolated Codex CLI invocations while leaving trusted status authority in ResearchEvolve Core and Lean.

## Default actor path

Each Explorer, Conjecturer, Proof Planner, Prover, Proof Reviewer, Formalizer, Formal Repairer, or Tactic Generator call follows this sequence:

```text
Core actor request
  -> role-specific field projection and recursive secret redaction
  -> immutable policy/context/prompt fingerprints
  -> fresh empty actor-session directory
  -> codex exec --ephemeral --ignore-user-config --sandbox read-only
  -> shell/MCP/plugins/apps/web/subagents/memory disabled
  -> role-specific JSON output schema
  -> Core response parser and deterministic trust gate
```

Planner, Prover, and Reviewer therefore use different Codex processes and session ids. The Reviewer receives the frozen ProofSpec, plan, and submitted proof artifact, but not the Prover's conversation or hidden reasoning. `prior_proofs` is removed from all proof-role context projections to prevent accidental cross-run contamination.

## Audit journal

`.researchevolve/plugin/state.sqlite3` now records `actor_runs` with:

- task, project, role, backend, and unique isolation session id;
- isolation policy, projected context, prompt, command, and output fingerprints;
- terminal status, exit code, elapsed time, and bounded diagnostics.

The journal deliberately does not store provider credentials or raw user configuration. Codex authentication remains available, but user `config.toml` is ignored. The actor subprocess receives a minimal environment allowlist; common API key/token variables are not inherited.

Inspect policies and runs with the MCP tools `research_actor_policy` and `research_actor_run_list`.

## Failure behavior

The native path fails closed on missing Codex CLI/authentication, timeout, non-zero exit, missing output, oversized output, invalid JSON, or role-schema mismatch. No model failure can create `empirically_supported`, `verified_natural_language`, or `formal_verified`.

`actor_backend=manual` preserves the v1.1 task exchange for explicit diagnosis or offline recovery. Manual tasks still receive projected/redacted context and schema validation, but they are not described as process-isolated.

## Install and check

```bash
python -m pip install -e ".[dev,plugin]"
research-evolve-plugin --root . doctor
pytest -q
```

The `codex` doctor check is required for the default actor path. Lean and Lake remain required only for formalization and fresh certificate replay.
