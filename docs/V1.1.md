# ResearchEvolve v1.1 — Codex Plugin MVP

v1.1 adds a Codex-native operating layer without moving trust out of ResearchEvolve Core.

## Contents

- repository plugin and marketplace manifests;
- five focused Skills for bootstrap, discovery, proof, formalization, and diagnosis;
- a local stdio MCP server with typed project, run, artifact, actor, semantic, and certificate tools;
- a project doctor and scaffold command;
- a SQLite WAL actor exchange journal with idempotency and optimistic concurrency;
- workspace confinement for every MCP path.

The stdio server exposes 19 typed tools covering doctor, project lifecycle, background discovery/proof/formalization, artifact queries, actor exchange, semantic validation, and certificate export/verification.

## Install

```bash
python -m pip install -e ".[dev,plugin]"
research-evolve-plugin --root . doctor
research-evolve-plugin --root . create my-project "State the mathematical objective"
```

Install the repository marketplace from `.agents/plugins/marketplace.json` in Codex. The plugin launches `research-evolve-mcp --root .` over stdio.

## Security and trust

The MCP layer does not accept arbitrary commands, does not call a model, and rejects absolute or root-escaping paths. Mutation tools require a `request_id`; actor output additionally requires the current task revision. Model output is only proposed data. Existing deterministic evidence, independent review, semantic audit, Lean kernel, axiom audit, and fresh-checker gates retain exclusive authority over trusted statuses.

## MVP boundary

Discovery, natural-language proof, and certified Lean formalization run as background jobs through fixed Core invocations. Codex answers the existing actor protocols through the journaled exchange bridge; the Core still performs schema parsing and all trusted gates. There is no UI in this release.
